WiFi Thermal Printer
Not configured
Steps:
1. Connect thermal printer to same WiFi network.
2. Find printer IP from its settings menu or router.
3. Most printers use port 9100 (RAW/ESC-POS).
4. Test connection, then save.
5. Use Save & Print on the billing page to print directly.

Most common reason printing fails: Browsers cannot open raw TCP sockets (port 9100). The app tries 3 methods automatically.

Best solution for WiFi printing:
1. Install RawBT (Android) or PrintHand (Android/iOS) app.
2. In RawBT: add your printer by IP and port 9100.
3. Set RawBT as default in your device print settings.
4. Use Browser Print button — it will route through RawBT automatically.

Alternatively, the ESC/POS binary file downloads automatically if WiFi fails — open it in RawBT to print directly.
